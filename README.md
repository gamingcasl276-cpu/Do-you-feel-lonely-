# Un lugar para ti — Lumi Gratis 🌿

Proyecto estático listo para GitHub Pages. No requiere Node.js, servidor, clave API, tarjeta ni pagos.

## Qué incluye
- Página adaptable a móvil y computadora.
- Selector de emociones con mensajes de apoyo.
- Pausa de respiración guiada (puedes detenerla cuando quieras).
- Chat Lumi con respuestas locales preparadas, contexto temporal básico y modos: charlar, distraerse, desahogarse y sorpresa.
- Juego de memoria, preguntas curiosas y cadena de palabras.
- Diario de un minuto que solo vive en la pestaña actual y se borra al recargar/cerrar.
- Mensaje editable para copiar y compartir con alguien de confianza.
- Orientación general para buscar apoyo humano.

## Probar en tu computadora
1. Descomprime el ZIP.
2. Abre `index.html` con doble clic. La página funciona directamente en el navegador; no hace falta `npm install` ni `npm start`.

## Publicar en GitHub Pages
1. Entra en GitHub y crea un repositorio nuevo, por ejemplo `un-lugar-para-ti`.
2. En esta carpeta, sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz del repositorio (no los pongas dentro de otra carpeta).
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`; pulsa **Save**.
6. Espera unos minutos y vuelve a **Settings → Pages** para abrir el enlace publicado.
7. Comparte ese enlace por WhatsApp.

## Importante sobre Lumi Gratis
Esta versión no es una IA generativa: usa reglas y respuestas preparadas, por lo que no entenderá todos los temas ni podrá improvisar como un modelo de lenguaje. El chat no hace solicitudes a una API. Los mensajes y el diario no se guardan en un servidor ni en almacenamiento persistente; al recargar o cerrar la pestaña se pierde el contexto y la nota.

## Cuidado y seguridad
Esta web ofrece acompañamiento general y no sustituye a un profesional ni a servicios de emergencia. Si alguien está en peligro inmediato, que busque a una persona de confianza que pueda estar físicamente presente y contacte con el servicio de emergencias o acuda al centro de urgencias más cercano.
